## Projeto principal

### 🐼 Pandas Gordos PRO

Aplicativo desktop para jogadores, construtores e administradores de Minecraft. O projeto reúne em uma única experiência:

- **PandaMap** para exploração de seeds, biomas, estruturas e dimensões;
- **PandaSync** para análise de mods, loaders, dependências e atualizações;
- **Panda AI** com modelos NVIDIA NIM configurados pelo usuário;
- ferramentas de geometria, comandos, cálculos, waypoints, projetos e servidores;
- suporte a Minecraft Java e Bedrock;
- temas claro e escuro, português e inglês, escala e densidade ajustáveis;
- atualizações assinadas, armazenamento protegido de credenciais e backups controlados.
